TokyoRailMap 隐私政策

生效日期：2026-06-23

TokyoRailMap 是用于查看东京都市圈铁路线路、站点、班次和路线规划的工具。本应用不提供账号系统，不投放广告，不内置第三方统计 SDK，不出售个人数据，也不会主动收集或上传你的精确位置。

1. 适用范围

本政策适用于 TokyoRailMap 的网页端、Electron 桌面端、Android 端和 iOS 端。项目开发者为 Blysh。你可以通过 GitHub Issues 或应用商店开发者联系渠道提交隐私相关问题。

2. 我们不会收集的内容

  • 不要求创建账号，也不收集姓名、邮箱、电话号码或支付信息。
  • 不请求系统定位权限，不收集 GPS、后台位置或行程轨迹。
  • 不读取通讯录、日历、短信、麦克风、摄像头或健康数据。
  • 不内置广告 SDK、行为分析 SDK 或跨应用追踪 SDK。
  • 不出售个人数据。

3. 本地保存的数据

为了让应用可用，TokyoRailMap 会在你的设备或浏览器本地保存少量设置和使用偏好，例如：

  • 主题、底图、导出格式等应用设置；
  • 搜索历史、收藏状态和最近使用记录；
  • 导出图片或 PDF 时生成的临时文件。

这些数据默认保存在你的设备或浏览器本地，不会由 TokyoRailMap 上传到开发者服务器。你可以通过浏览器清除站点数据、卸载应用，或使用系统提供的应用数据清理功能删除这些本地数据。

4. 权限使用

  • 网络访问：用于加载应用资源、地图字体、第三方开源前端库以及地图/铁路数据文件。
  • 相册/媒体权限：仅在你主动保存或分享导出的铁路图、截图、班次图片时使用。应用不会扫描、分析或上传你相册中的既有照片或视频。
  • 文件保存与分享：当你选择导出、保存或分享图片/PDF 时，系统分享面板或你选择的第三方应用可能会处理该文件；这些第三方应用的处理方式适用其各自隐私政策。

5. 网络请求与第三方服务

TokyoRailMap 尽量以本地静态资源运行，但在部分环境中可能访问以下第三方或托管服务：

  • GitHub Pages / GitHub Releases：用于网页访问、下载或更新应用资源。
  • jsDelivr：在导出图片或 PDF 时按需加载 html2canvas、jsPDF 等开源前端库。
  • MapLibre demo glyphs：用于本地 PMTiles 极简底图的地图文字字体资源加载。
  • 本地 PMTiles 极简底图：极简模式使用随应用打包的 tiles/kanto.pmtiles，不会为了浏览极简底图向 OpenStreetMap 官方瓦片服务发送地图浏览请求。
  • OpenFreeMap：详细、深色详细和 3D 底图会按需向 OpenFreeMap 请求样式、矢量瓦片和字体资源；相关地图数据 attribution 包括 OpenFreeMap、OpenMapTiles 与 OpenStreetMap contributors。

访问这些网络资源时，第三方服务器可能会按其自身日志规则接收 IP 地址、User-Agent、请求时间和请求 URL 等基础网络信息。TokyoRailMap 不会向这些第三方发送你的账号信息，因为本应用没有账号系统；也不会主动发送你的精确位置。

6. 数据分享

TokyoRailMap 不会将个人数据出售给广告商或数据经纪商。除以下情形外，我们不会主动向第三方分享数据：

  • 你主动使用系统分享功能，把导出的图片、SVG、ZIP 或 PDF 发送给其他应用；
  • 为了加载应用运行所需的第三方静态资源而产生的基础网络请求；
  • 法律法规、监管机关或司法机关依法要求披露的情形。

7. 数据保留与删除

本地设置、搜索历史和收藏记录会保留在你的设备上，直到你清除浏览器站点数据、清除应用数据或卸载应用。导出的图片/PDF 由你保存到本地文件系统或相册后，由你自行管理和删除。由于 TokyoRailMap 没有账号系统和开发者服务器，通常不存在需要向开发者申请删除的云端账号数据。

8. 儿童隐私

TokyoRailMap 面向一般出行信息查询场景，不以儿童为主要目标用户。我们不会有意收集儿童个人信息。如果你认为本应用意外处理了儿童个人信息，请通过本政策中的联系方式告知。

9. 数据安全

TokyoRailMap 以静态应用和本地处理为主，尽量减少需要上传的数据。网络资源会优先通过 HTTPS 加载。请注意，任何通过系统分享面板发送给第三方应用的文件，将由你选择的第三方应用继续处理。

10. 政策更新

如果 TokyoRailMap 后续新增账号、云同步、定位、统计分析、广告或其他会改变数据处理方式的功能，本政策会随之更新，并在应用内或发布说明中提示重要变化。

11. 非官方声明

TokyoRailMap 不是铁路运营商官方应用。线路、站点、票价和班次信息仅供参考，请以各运营商官方公告和现场信息为准。
