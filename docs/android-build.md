# Android Build Notes

This project keeps the existing browser/Electron app intact and adds Android as a Capacitor shell.

## Current Flow

1. Sync local browser assets:
   ```bash
   npm run cap:web
   ```
2. Sync the Android project:
   ```bash
   npm run cap:sync:android
   ```
3. Check local build tools:
   ```bash
   npm run android:doctor
   ```
4. If `android:doctor` reports missing SDK components, accept the Android SDK license interactively and install the required packages:
   ```bash
   npm run android:sdk:licenses
   npm run android:sdk:install
   ```
5. Build the debug APK:
   ```bash
   npm run android:build
   ```

## Expected SDK Components

The Android project generated by Capacitor currently requires:

- `platforms;android-36`
- `build-tools;36.0.0`
- `platform-tools`

The helper scripts detect Homebrew OpenJDK at `/opt/homebrew/opt/openjdk/libexec/openjdk.jdk/Contents/Home` and the default Android SDK at `~/Library/Android/sdk`.

## Validation Checklist

Run these after any Android packaging change:

```bash
npm run test:android
npm run cap:sync:android
npm run android:doctor
```

After the SDK license and packages are installed, also run:

```bash
npm run android:build
```

## Notes

- Do not accept the Android SDK license automatically in scripts; it must remain an interactive user action.
- Do not commit generated `www/` or `android/app/src/main/assets/public/` contents.
- Do not use Android packaging work as an opportunity to refactor the map, route, search, hover, or panel business logic.
